## 새 화면 — 날짜 Picker (NEW · ★ v1.5 · DATE PICKER)

**문제:** 현재 TRIP START "강릉" chip 탭 → 즉시 SCENARIO 02.5 로 진입. `startDate`/`endDate` 가 `오늘 + 2박 3일` default 로 자동 박힘. 사용자가 *몇 박 며칠* 결정 화면 없음.

**위치:** TRIP START → **DATE PICKER (신규)** → SCENARIO 02.5 (일자별 날씨) → SCENARIO 03 (POI)

**spec:**
- 헤더: 잉크 마크 + "{city} · 며칠 머물래요?"
- voice 인용: "언제, 몇 박으로?"
- 출발일 picker:
  - **horizontal scroll calendar row** — 오늘 ~ +30일 (날짜 카드 풀)
  - 각 카드: DM Mono 9px 요일 + Fraunces italic 18px 일 + Noto Serif 11 월
  - selected = celadon border + bg celadonTint
- 박수 picker:
  - row "당일 / 1박 2일 / 2박 3일 / 3박 4일 / 더…"
  - chip 패턴 (TRIP START 의 인기 8 chip 와 동일 스타일)
  - selected = celadon bg + bg-elev color
- 미리보기:
  - "5월 14일 (화) ~ 5월 16일 (목) · 2박 3일" 친구 톤 한 줄
- CTA "이렇게 가요" → setPlanningStep('dates') (또는 새 step 'date_picker' → 'dates') → SCENARIO 02.5

**type contract:**
- 기존 `Trip.startDate/endDate` 그대로 사용 (날짜 picker 결과 박음)
- 새 step 추가? 또는 기존 TRIP START 후 즉시 진입. 단순화 위해 **TRIP START 안에서 chip → date picker → 02.5** 순.

**design-preview 추가 필요:** 신규 SCENARIO 02.4 화면 markup 도 design-preview.html 에 추가 (직역 출처 확립).
